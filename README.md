# Unix & Linux OSes 🐧

A large, community-friendly catalog of Linux distributions and other Unix-like operating systems. This list is intended as a quick reference for discovering what an OS is for, what it is based on, and where to learn more.

> **Sources & discovery:** This catalog is informed by project websites, DistroWatch, DistroFinder, LinuxDistroFinder, and Wikipedia. Descriptions are intentionally short summaries rather than official project wording.

## Quick categories

- 🖥️ **Desktop:** everyday computing, work, school, browsing and customization
- 🎮 **Gaming:** gaming, Steam, performance tuning and console-style systems
- 🔐 **Security:** privacy, security testing, forensics and defensive research
- 🪶 **Lightweight:** older or low-resource computers
- 🛠️ **Developer:** programming, containers, servers and development
- 🏢 **Enterprise:** long-term support, servers and business workloads
- 🧪 **Advanced:** rolling releases, source-based systems and highly customizable distros
- 📦 **Immutable:** atomic updates, rollback and image-based system management
- 📱 **Mobile/embedded:** phones, tablets, ARM boards and specialized hardware

Found a distro that is missing, renamed, discontinued, or has a better official link? Open an issue or pull request. Useful additions include:

- Distribution name
- Official website
- Base/family
- Main purpose or target audience
- Desktop environment or interface, when relevant
- Whether it is active, discontinued, or historical
- A short neutral description
