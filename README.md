# Unix & Linux OSes 🐧

A giant catalog of Linux distributions, Unix-like systems, BSDs, experimental operating systems, community projects, security distributions, command-line systems, and unusual OS projects.

The goal is to make this a huge discovery list: what an OS is, what it is useful for, what family it belongs to, and where to learn more.

## Quick categories

- 🙂 Easy / beginner-friendly OSes
- 🧩 Configuration-heavy / DIY OSes
- 🖥️ Desktop

- 🔐 Security & privacy
- 🪶 Lightweight
- 🛠️ Developer
- 🏢 Enterprise

- 📦 Immutable / atomic
- 📱 Mobile & embedded
- 🖥️ Server / self-hosting

- 🧬 Experimental / research
- 🐚 BSD / Unix-like
- ☀️ illumos / OpenSolaris

## How the categories work 🗂️

An OS can appear in multiple categories. For example, Arch Linux can be both **configuration-heavy** and **terminal-friendly**, while Bazzite can be both **gaming** and **immutable**. Categories describe common use cases rather than strict technical classifications.

### Easy does not mean limited

Easy distributions can still be extremely powerful. The category mainly means they try to reduce the amount of manual setup required to get a useful system running.

### Configuration-heavy does not mean bad

These systems are listed here because they give the user a lot of control. Some people enjoy configuring everything; others would rather install something ready to use.
