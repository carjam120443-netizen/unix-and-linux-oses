# Unix & Linux OSes 🐧

A giant, community-friendly catalog of Linux distributions and other Unix-like operating systems. Use it to discover what an OS is for, what it is based on, and where to learn more.

> **Sources & discovery:** Project websites, DistroWatch, DistroFinder, LinuxDistroFinder, Wikipedia, and community distro directories. Descriptions are short summaries, not official project wording.

## Quick categories

- 🖥️ **Desktop** — everyday computing, school, work, browsing and customization
- 🎮 **Gaming** — Steam, Proton, gaming-focused desktops and handhelds
- 🔐 **Security & privacy** — security testing, forensics, isolation and privacy
- 🪶 **Lightweight** — older computers, small installs and live systems
- 🛠️ **Developer** — programming, containers, build systems and servers
- 🏢 **Enterprise** — production servers, business and long-term support
- 🧪 **Advanced** — rolling, source-based, unusual or highly customizable systems
- 📦 **Immutable / atomic** — image-based systems, rollback and atomic updates
- 📱 **Mobile & embedded** — phones, tablets, routers, boards and appliances
- 🐚 **BSD / Unix-like** — systems outside the Linux kernel ecosystem

Want to add another OS? Add it to the appropriate category with:

1. OS/distribution name
2. Base or family
3. Short description of what it is useful for
4. Official project link when available

Please avoid presenting a distro as objectively “best.” Different systems are built for different goals.
