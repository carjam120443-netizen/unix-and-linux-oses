# Unix & Linux OSes 🐧

A giant, community-friendly catalog of Linux distributions and other Unix-like operating systems. Discover what an OS is for, what it is based on, and where to learn more.

> **Sources & discovery:** Official project sites, DistroWatch, DistroFinder, LinuxDistroFinder, Wikipedia, ArchWiki, and community directories. Descriptions are short summaries rather than official project wording.

## Quick categories

- 🖥️ **Desktop** — everyday computing, school, work, browsing and customization
- 🎮 **Gaming** — Steam, Proton, emulation, gaming PCs and handhelds
- 🔐 **Security & privacy** — auditing, forensics, isolation and privacy
- 🪶 **Lightweight** — older hardware, tiny installs and live systems
- 🛠️ **Developer** — programming, containers, build systems and development
- 🏢 **Enterprise** — production servers, business and long-term support
- 🧪 **Advanced / source-based** — rolling, source-built and highly customizable systems
- 📦 **Immutable / atomic** — image-based systems, rollback and atomic updates
- 📱 **Mobile & embedded** — phones, tablets, routers, boards and appliances
- 🖥️ **Server / self-hosting** — NAS, homelab, cloud and infrastructure
- 🤝 **Community distributions** — volunteer-led, enthusiast-built and independent projects
- 🧬 **Experimental / research** — unusual kernels, microkernels and OS research
- 🐚 **BSD / Unix-like** — systems outside the Linux kernel ecosystem

## Contribution guidelines

Want to add another OS? Add it to the most appropriate category with:

1. OS/distribution name
2. Base or family
3. Short description of what it is useful for
4. Official project link when available
5. Community/wiki link when an official site is unavailable
6. Mark it as **community**, **experimental**, **inactive**, or **historical** when that status matters

Please avoid presenting a distro as objectively “best.” Different systems are built for different goals.

## Disclaimer

This is a community-maintained reference list. Projects can change base distributions, desktops, goals, URLs, ownership, or development status. Check the linked project site before installing or relying on an OS for important work.
